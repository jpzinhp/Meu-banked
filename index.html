Integrações e chaves de API (backend)

Meu perfil
Isso identifica você neste navegador (personaliza o "Olá" do painel) — não é um login seguro: não tem senha, não sincroniza entre dispositivos, e qualquer pessoa que abrir este arquivo no seu computador vê os mesmos dados. Login de verdade (com senha e sincronizado) precisa do backend conectado — veja a nota abaixo.
Dados salvos neste navegador
Empresas buscadas, sites gerados e leads ficam salvos automaticamente neste navegador (localStorage) — continuam aqui mesmo se você fechar a aba ou desligar o computador. Não ficam salvos na nuvem nem sincronizam com outro dispositivo/navegador — para isso, é preciso o backend com banco de dados real (Supabase), como já estava no plano original.
Modo real (backend)
Informe a URL do backend publicado (veja o pacote business-discovery-server que te entreguei — usa a Local Business Data API, gratuita e sem cartão). Com isso conectado, a busca de empresas passa a usar dados 100% reais do Google Maps (nome, telefone, endereço, avaliação e fotos) para qualquer cidade e nicho. Os textos do site continuam gerados no modo simulado, a menos que você também configure uma chave de IA paga — sem isso, tudo funciona igual, só o texto não é gerado por IA.
○ Nenhum backend conectado — o app está em modo demonstração.

Cobertura de dados reais pré-coletados (modo demo)
Todas as 27 capitais do Brasil têm pelo menos Restaurantes com dados reais. São Paulo tem 23 tipos de negócio diferentes. Rio de Janeiro e Belo Horizonte têm 5 tipos cada. As demais capitais (Salvador, Brasília, Manaus, Goiânia, Florianópolis, Belém, Vitória, Natal, Maceió, João Pessoa, Aracaju, Cuiabá, Campo Grande, São Luís, Teresina, Porto Velho, Rio Branco, Macapá, Boa Vista, Palmas, Curitiba, Porto Alegre, Fortaleza, Recife, Campinas) têm pelo menos 1 nicho carregado com dado real. O campo de cidade sugere qualquer município do Brasil (via IBGE) — fora das combinações listadas, sem o backend real conectado, a busca não retorna resultado (em vez de inventar empresas).
Sobre o modo demonstração
Este ambiente roda com dados públicos pré-coletados (marcados DADOS REAIS) e, fora dessas combinações, não preenche resultados — para validar o fluxo completo (busca, oportunidade, análise, geração de site e leads) sem consumir API real. Conecte o backend acima para busca 100% real e ilimitada.
